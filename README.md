# Breast Cancer Classification Using SVM

## Objective

The objective of this project is to develop a machine learning classification model that predicts whether a breast tumor is benign or malignant.

## Dataset

The Breast Cancer Wisconsin dataset was used for this project. The dataset contains measurements of cell characteristics that can be used to classify tumors.

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Methodology

The following steps were performed:

1. Loaded and explored the dataset.
2. Checked for missing values.
3. Cleaned the dataset.
4. Separated features and target variables.
5. Split the data into training and testing sets.
6. Standardized the numerical features.
7. Trained a Support Vector Machine (SVM) classifier.
8. Generated predictions on the test dataset.
9. Evaluated the model using accuracy and classification metrics.
10. Created a confusion matrix.
11. Generated an ROC curve and calculated the AUC score.

## Model Evaluation

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC Curve
- AUC

## Conclusion

The SVM model was successfully trained to classify breast tumor samples. The evaluation metrics and visualizations provide an overview of the model's classification performance.
